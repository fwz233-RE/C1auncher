# Music Player — 墨水屏界面

适用于 C1-Slim 的 296×152 单色屏。界面采用细线、留白与唱片插画，不使用底部反色大黑条；播放控制沿用既有行为。

## 音乐目录

默认读取 `/storage/mtp/Music` 中的 MP3、FLAC 文件（含子目录）。主页启动时自动创建 `Pic`、`Music`、`Book` 三个目录；音乐应用独立运行时也会补建缺失的 `Music` 目录。原来的小写 `music` 目录中的内容不会被删除或自动搬移。

## 界面

- 左侧为 98×98 封面或播放动效，有专辑封面时静态模式仍显示原封面。
- 默认封面改为单色唱盘插画，包括细唱片纹、唱臂和点阵阴影。
- 右侧为播放状态、顺序/随机、双行歌名、选曲提示、进度与时间。
- 底部为白底短提示和音量，和封面之间保留独立空白带。
- 歌名使用 18 像素、辅助中文使用 16 像素；以单色字形覆盖率阈值渲染，避免小字号中文断笔。

## 按键与视效

- 方向键、OK、P、音量和返回键保持原有播放功能。
- 音量调整成功后立即保存到 `/usr/data/c1/music-player/volume.json`，下次打开时恢复显示值并应用到实际混音器；静音 `0` 也会保留。缺失或损坏的设置使用默认 `50`。只在音量变化时保存，切换视效不影响音量；保存失败会提示，并保持界面显示已实际生效的音量。
- `V` 循环切换：静态封面 → 柱状律动 → 唱片 → 静态封面。
- 默认静态。静态模式的播放进度约每 10 秒更新一次；动态模式文字进度约每秒更新一次，封面动画在上一帧提交完成后等待 700 毫秒再更新。实际动画周期还包含屏幕写入和渲染耗时，不能当作实测面板帧率。按键、曲目切换、暂停和错误状态及时更新。
- 律动柱和唱片是**装饰性播放动效，不是从音频采样计算的真实频谱**。界面使用“律动”“播放动效”描述，不显示假频率或假分贝。
- 动效使用仅在播放中启用的单次定时器，并缓存 16 个封面动效帧；更新时只替换封面区域，不重新栅格化中文和整套布局。播放器通过设备的快刷写帧路径提交，不主动触发全屏刷新。
- 暂停、待机或切回静态会停止并清空动画定时器；慢帧不积压、不补播。暂停时唱片冻结，柱状图回落到静止状态。
- 快刷策略参考 `ChiChuGames/src/platform/display.c`：`fast_refresh_only=1` 抑制自动全刷，直接写 `/dev/epaper_lcd`，相同帧跳过；游戏使用各自的 tick 周期，音乐动效使用 700 毫秒等待间隔。
- 进入应用及从播放转为暂停/停止时全刷；播放中及一般按键使用快速刷新，避免持续全屏闪烁。这里的快速刷新仍通过整帧显示驱动提交，并非硬件局部刷新。
- 视效偏好仅在切换时写入 `/usr/data/c1/music-player/display.json`，重新打开仍保持选择。缺失或损坏时回到静态模式。

## 本地预览和测试

Windows PowerShell：

    $env:C1_FONT_PATH = 'D:\AI\MiSans-Normal.ttf'
    go test ./...
    go run . --preview D:\c1slim\build\music-ui-preview

预览使用和设备完全相同的渲染函数及 1-bit 帧打包，输出原始 296×152 和三倍最近邻放大 PNG。覆盖静态、动态、暂停、长歌名、待选、专辑封面及空库状态。预览代码不编入 MIPS 设备版本。

构建需要显式传新版本号：

    .\build.ps1 -Version 0.3.3

可通过 `C1_FONT_PATH`、`C1_MUSIC_DIR`、`C1_MUSIC_DISPLAY_SETTINGS`、`C1_MUSIC_VOLUME_SETTINGS` 覆盖运行路径。

## 发布验收

发布新版本应保留仓库其他应用，使用签名索引和包管理器安装；不要覆盖已发布版本的二进制。核对 `current` 链接、`.c1pkg-entry`、设备执行版本和本地/设备/发布包 SHA-256。刷新频率不等于实测耗电量，续航提升仍需真机功耗测试。
