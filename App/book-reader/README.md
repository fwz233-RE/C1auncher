# Book Reader

面向 C1 小屏设备的离线阅读器。默认读取设备 `/storage/mtp/Book`（含子目录）；新增书籍后重新启动阅读器。

## 0.1.22：音量键、章节页码与导航布局

- 书架、章节目录、书签列表：音量加向下选择，音量减向上选择；正文中音量加下一页、音量减上一页。百分比输入界面仍保留音量加增加数值、音量减减少数值。
- 正文右上角显示当前章节的 `页 3/25`（第 3 页，共 25 页），其右侧仍显示全书百分比。章节标题按剩余宽度截断，正文尺寸和字形不变。
- 页数按当前点阵字体从章节起点计算，包含超过 4 MiB 的多个读取窗口。恢复进度、书签和百分比跳转保留字节位置；若落在一页中间，首屏显示该页剩余部分，后续页保持标准边界。
- 目录、书签页底部按 `←返回  ↑上移  ↓下移  →阅读/跳转` 分开排列，左右位于两端，上下位于中间；目录的展开/收起提示仍随所选项目变化。
- 目录顶部 `O跳转` 旁边放置 `P书签`；书签页顶部为 `O跳转` 和 `P删除`。从书签页打开百分比跳转后，可取消回书签，或阅读后按左键回书签。
- 首次打开未缓存章节会扫描该章来统计总页数，超大章节可能等待更久；仅缓存当前章节的页边界，渲染页码时不读文件。

## 0.1.21：中文点阵字体与书籍格式

- 书架、目录和正文使用与包管理器完全相同的 GNU Unifont 16.0.04 位图字形：中文 16×16、窄字符 8×16。原生像素输出，不缩放、不抗锯齿、不作灰度抖动。正文行距 20px。
- 字库包含 30,064 个字形，直接内嵌程序，不再依赖外部 `MiSans-Normal.ttf`，也不再读取 `C1_FONT_PATH`。未覆盖的罕见字符显示替代字形，不保证全部 Unicode 字符都有字。
- TXT 支持 UTF-8（含 BOM）、GB18030，以及带 BOM 的 UTF-16LE/BE。`〖…〗`、`【…】` 等包裹式卷章标题可识别；异常 GB 字节显示替代字形，同时保留原始字节偏移，避免书签偏移。
- EPUB 支持离线读取 OPF spine 顺序的 XHTML/HTML 正文，使用 NCX / EPUB 3 导航标题及锚点组织目录。忽略非正文脚本、样式；不下载外部资源、不执行脚本。当前是纯文字阅读，不还原 CSS 排版、插图、表格布局或交互脚注；加密/DRM EPUB 明确报错。
- EPUB 和 UTF-16 转换缓存保存在 `/usr/data/c1/book-reader/documents`（随 `C1_BOOK_READER_HOME` 改变，或用 `C1BOOK_READER_CACHE_DIR` 单独指定）。书籍目录不需要写权限；进度、书签仍绑定原始书籍路径及指纹。缓存可重建，更新软件不需要重新导入书籍。
- ZIP 限制为最多 10,000 个条目、单条目 32 MiB、总展开量 256 MiB，元数据 4 MiB；限制异常压缩比及 XML 嵌套深度。路径穿越、重复/加密条目、缺失 spine 资源等拒绝解析。
- 原书籍保留不变；本地测试用书不随程序分发。
- 字库由 `tools/generate_bitmap.py` 从 `C1ancher/src/pkg/font_generated.h` 原样转换；许可证在 `assets/font-LICENSE.txt`，为 SIL OFL 1.1。


## 卷与章节目录

- 只有识别出的卷号从 1 开始、按原书顺序连续且使用同一种单位（卷、部或篇）时，才显示一层分组。支持中文数字、中文大写数字、阿拉伯数字及全角数字，例如“第一卷”“第壹卷”“第1卷”“卷一”。当前不是“部 → 卷 → 章”的多层树。
- 没有卷标题，或卷号缺失、跳号、倒序、无法确定、混用单位时，使用普通章节列表。例如“第一卷、第三卷、第六卷”不会显示分卷，也不会猜测补齐缺失卷号。
- 确定键（Enter/OK）和右键均可打开所选章节；选中卷时展开/收起卷。左键或 BACK 从子章节收起所在卷，再按返回书架。
- 上下键在可见项目间移动，长按每次移动 5 项。隐藏章节不会占用导航步骤。
- 目录、书签和正文中按全键盘 O 打开全书百分比跳转；目录中 P 打开书签。
- 跳转界面保留上下拨杆每次调整 1%、长按每次调整 5%。也可以直接输入 `19.65`、`99.99`，范围为 0–100，最多两位小数。
- 设备顶排 Q/W/E/R/T/Y/U/I/O/P 按键在跳转界面对应其印刷数字 1/2/3/4/5/6/7/8/9/0；Z 输入小数点，DEL 逐位删除，也接受独立数字键及小数点键。进入后第一次输入会替换默认值。O 在此界面输入 9，P 输入 0。
- 跳转界面按确定键（Enter/OK）或右键确认；左键或 BACK 取消，不改变原阅读位置。超出范围的输入会提示修正，不会直接跳转。
- 卷首有说明文字时显示“卷首正文”；重复卷标题后有文字时显示“卷内正文”。仅有卷标题、空行或常见分隔线的部分不会产生正文入口或空白翻页。
- 同一卷中重复出现的同名卷标题（允许空白、全/半角冒号和数字写法差异）合并为一个目录分组；若切换到其他卷后又回到旧卷号，则不满足连续性要求，整本书改用普通章节列表。
- 分组模式下，目录卷数为分组数，章数不包含卷标题和自动生成的前言入口。普通章节列表保留可读的卷首说明，跳过纯卷标题。
- 有效分组中的正文、书签和百分比预览使用原书卷标识，不重新编造卷号。

## 与现有功能的兼容

底层 `Document.Chapters` 继续保留原来的顺序及每段的字节范围。目录树只提供展示和导航，不使用可见行号存储阅读位置。

- 阅读进度、书签文件格式及 `layoutVersion` 不变。
- 章节缓存升级到版本 3，重扫包裹式卷章标题，并将派生数据放入私有缓存目录；旧缓存会自动重建。此操作不修改书籍内容，也不删除阅读进度和书签。
- 恢复进度、打开书签、百分比跳转或跨卷翻页后，目录会选中目标章节；启用分组时还会展开对应卷。
- 从书签进入正文仍显示“←书签”，左键返回书签列表。
- 旧位置若恰好落在纯卷标题或纯分隔线处，会定位到下一处可读内容；书尾则定位到上一处可读内容。原存档记录不会因为目录分组而批量改写。
- 新增标题识别可能拆分原来未识别的 TXT 大章节；恢复进度及书签时按保留的原始字节位置定位新章节，不因为目录编号变化退回书首。

## 测试

在此目录运行 `go test ./...` 和 `go vet ./...`。

可选环境变量：

- UI 测试直接使用内嵌的包管理器点阵字库，不需要本地 TTF 字体。
- `C1_UI_PREVIEW_DIR`：输出与设备相同的 296×152 PNG 预览。
- `C1_TEST_BOOK_PATH`：只读扫描本地 TXT 验证卷章结构，不在书籍旁生成缓存。
- `BOOK_READER_TEST_BOOKS`：三本用户样本所在目录，执行只读编码诊断、全章分页、原生字体分页和进度/书签测试；默认跳过。测试只输出统计数据，不输出书籍正文，使用临时缓存。

## 构建与预览

运行 `build.ps1 -Version 0.1.22`，默认输出至仓库 `build/book-reader-0.1.22/payload/book-reader`。构建会运行主机测试和 vet，生成静态 MIPS 小端硬浮点 ELF 并检查 ABI。字库已内嵌，不需要本机 TTF 文件。主机预览在设置 `C1_UI_PREVIEW_DIR` 后由测试生成，`native-body.png` 使用合成示例文字而非书籍摘录。

回归测试覆盖：无卷书籍、卷首正文、空卷、重复卷标题及补充正文、中文/大写/阿拉伯卷号、卷号缺失及倒序回退、分隔线、UTF-8/BOM/CRLF/GB18030、旧缓存和存档兼容、目录展开收起、确定键打开章节、跨卷翻页、书签来源、顶排数字及小数百分比输入、删除/取消/非法输入处理和真实书籍跳转。
