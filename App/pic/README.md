# 图片查看器

## 0.1.4 操作

- 默认读取 `/storage/mtp/Pic`，同时兼容同级 `pic` 和 `Pictures` 及其子目录，不移动原文件。`C1_PICTURES_DIR` 自定义时只扫描指定目录。
- 支持 JPG/JPEG、PNG、GIF 首帧，以及本机 296×152、5624 字节的 RAW 壁纸。`wallpaper.raw` 也能直接查看。
- 上/左：上一张；下/右：下一张。
- OK：切换普通预览和无界面全屏。全屏保持比例，未覆盖部分留白，不裁切原图。
- P：进入全屏壁纸确认；OK 确认覆盖，返回取消。不要求长按，重复按键不会直接确认。
- R：重新扫描，尽可能保留当前选中图片。
- 返回：已加载的全屏先回预览，预览再返回退出；加载过程中返回会取消并退出。
- 保留终端 D 删除入口，但增加明确确认，P 不再删除文件；固定 `wallpaper.raw` 禁止从此入口删除。

## 壁纸保存保证

普通浏览、切图、全屏、加载失败都不修改壁纸。只有用户执行 P → OK 才保存到规范目录中的 `wallpaper.raw`，不会写到 `Pictures` 或相册子目录。

保存使用与纯全屏显示相同的 296×152 单色帧，排除标题、提示、确认框。新帧写入同目录临时文件并同步，随后原子替换，再同步目录。替换前出错会保留旧壁纸；替换后目录同步失败会报告错误，不能保证断电持久性。核心下次绘制锁屏时重新读取这个文件。

## 内存策略和限制

一次只解码一张选中图片；方向键取消前一个任务，待处理队列只留最后一次选择。不会同时预解码多个原图。加载期间先显示状态，事件循环继续接收按键，完成后显示整幅结果，不把半张图当作可保存壁纸。

- 普通基线 JPEG：按最小编码块增量读取，仅对输出需要的块执行变换。
- 非交错 PNG：逐行解压，仅保存两行和屏幕尺寸输出；校验 CRC、行滤镜及透明度。
- PNG 透明区域按白色背景合成，最后进行设备单色抖动。
- 大型渐进式/多扫描 JPEG、交错 PNG 等变体暂不做完整解码，只允许不超过 262144 像素的小图安全回退；超过则明确拒绝，避免占满设备内存。GIF 只读取首帧并受同样的小图限制。
- 文件最多 64 MiB，源图最多 1 亿像素、单边最多 65535，PNG 解压行数据最多 512 MiB；这些是拒绝上限，不是一次分配的内存。
- 缩小采用采样；暂不应用 EXIF 自动旋转和色彩配置文件。
- 媒体扫描限制 4096 张、1024 个目录和 16 层深度，跳过符号链接；部分目录失败不隐藏其他已找到图片。
- Go 的 16 MiB 内存目标仅是辅助设置，不视为硬限制；主要保障来自解码结构和分配上限。

## 开发验证

Windows 主机：明确设置 `GOOS=windows GOARCH=amd64 CGO_ENABLED=0`，运行 `go test ./...` 和 `go vet ./...`。设置 `C1_PIC_TEST_FONT` 可运行实际中文字体渲染测试；`C1_PIC_PREVIEW_DIR` 仅供测试输出软件渲染预览，并非设备照片。

`pic --check-library` 只读输出发现数量与格式统计。`pic --check-image <path>` 不打开屏幕、不改壁纸，输出解码耗时、渲染帧 SHA-256、Go 分配量和 Linux 峰值 RSS；该进程未加载中文字体，不能将其 RSS 当作完整交互应用的内存占用。
