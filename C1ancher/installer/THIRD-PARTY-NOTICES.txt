C1-Slim Windows 安装器第三方组件说明

本目录包含 C1SlimInstaller.exe、外置 Android platform-tools、neofetch 和 c1publish。核心签名组件仅在维护者提供完整 enrollment 后加入。请保留所有附带许可文件。

1. Microsoft .NET 8 / Windows Desktop Runtime
安装器以 Windows x64 self-contained 形式发布，运行所需的 .NET 组件在 EXE 内。
项目与许可证：https://github.com/dotnet/runtime/blob/main/LICENSE.TXT
第三方声明：https://github.com/dotnet/runtime/blob/main/THIRD-PARTY-NOTICES.TXT
Windows Desktop：https://github.com/dotnet/windowsdesktop

3. Android SDK platform-tools
只附带 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll。原始版权与许可声明见同目录 PLATFORM-TOOLS-NOTICE.txt。安装器不附带 USB 驱动，电脑可能需要单独安装匹配的设备驱动。
来源：https://developer.android.com/tools/releases/platform-tools

4. neofetch
原始许可见 payload/accessories/LICENSE.md。neofetch.upstream 保留上游实现，neofetch 与 c1-config.conf 为设备适配入口与配置。

5. c1publish / Go runtime
c1publish 的 Go 运行时许可见 GO-LICENSE.txt。Windows / Linux 发布程序在电脑运行，不是设备上的 MIPS 应用。
