## 页面及键位

- 默认只有一页，每页仍是八拍、16 个八分音符格点，每格最多八个触发事件。
- 短按 I：上一页；短按 O：下一页。只切换已有页面，首尾不回绕、不自动创建。
- 长按 I 约 700 毫秒：在当前页之前插入空白页；长按 O：在当前页之后插入空白页。
- 插入后选中新页第 1 格，已有页的内容和先后顺序保留，序号自动按 1、2、3……重排。例如在原第 1 页左侧插入，新页成为第 1 页，原第 1 页成为第 2 页。
- 长按一次只创建一页，必须松开再按才能继续创建；即使右侧已有页面，长按 O 仍是在当前页右侧插入，而不是跳到末尾追加。
- 最多 64 页，到上限只提示 `PAGE LIMIT: 64`。没有单独的删除页、复制页或移动页功能。
- 按下 I/O 就暂停自动走格，按下时以实际播放进度确定当前页。短按在松开时翻页，长按到阈值时创建；录制开关保持原状，已有手弹持键不被强制切断。
- 左右方向键始终只在当前页的 16 格内选格，保留原先逐格模式的操作。
- I/O 同时按或夹杂其他按键会取消尚未触发的翻页／插入，减少组合键误操作。帮助、输入重置、电源键事件、导出和主循环长时间停顿也会取消待触发手势。
- P 继续用于 WAV 导出，不承担建页或自由时长录音功能。

## 界面

主界面的琴键、鼓声、音名、16 格进度和原有文字位置不变。只在黑色标题栏的空白区域 `x=217..287, y=3..19` 绘制页码：

- 当前页固定在中间，白底黑字，23×17 像素。
- 左右相邻页使用白色细边，黑底白字，19×11 像素。
- 最多三个页码；第一页隐藏左邻页，最后一页隐藏右邻页，单页只有中间页码。
- 两位数页码也在原槽位内，不推动标题或其他区域。
- 帮助页保留八行布局，补充 I/O 短按和长按操作；操作结果使用原底部提示区域。

预览在 `build/multipage-preview-01/`，覆盖单页、首／中／尾页、两位数及第 64 页。它们是主机生成的三倍像素预览，不是真机屏幕照片。

## 播放、录制、导出

- 自动播放使用完整编曲的连续格点时钟，依次跨页，最后一页播放完回到第一页；空白页占据完整的 16 格时间，不被跳过。
- 在逐格模式按空格，从当前页当前格恢复自动播放，保留录制开关；自动播放中按空格停止并结束录制，再按则从停留页的第 1 格开始。
- 自动录制继续按最近八分音符格点量化，跨第 16 格时正确写入下一页；编曲尾部量化到头部时正确回到第一页。逐格录制只写选中的页和格。
- 速度、音量、当前音色及八度设置全工程共用；每个已录音符仍保存自己的音高／音色。调速保留当前页、当前格和格内进度。
- Delete 两次：普通模式下清空整个工程并恢复为 1 个空页面；逐格模式下 Delete 一次清空当前选中的单元格，保留其他格子和页面。
- P 从第一页第 1 格开始导出，到最后一页第 16 格结束，只导出一遍，末尾仍留一秒释放尾音空间。页与页之间不额外加静音或重建合成器。导出使用全部页面的深复制快照；退出可取消并删除未完成 WAV。
- 本功能扩展的是编曲长度，没有新增麦克风录音、任意时长音频录制、力度、跨格延音或多轨编辑。

## 保存、兼容及数据回撤

所有页面保存在一个 `song.json` 中，避免多个页面文件分别写入导致顺序与内容不一致。

- 单页保持 format 1，原有 `pattern` 字段为第一页；首次插页改为 format 2，新增 `pages` 数组保存第二页及后续页面。
- 新建页及实际翻页触发工程保存；既有约两秒后自动保存、Enter 保存和正常退出保存仍保留。当前浏览页和播放状态不持久化，重新打开从第一页空闲状态进入。
- 写入继续使用临时文件、文件同步、原子替换及目录同步。保存失败显示提示，未保存的内容修改仍保留 Dirty 状态供后续重试。
- 首次将磁盘上的 format-1 文件替换为 format 2 之前，独占创建 `song.json.v1-backup.json`，保存原文件的完整字节。已有且内容一致的备份可重用；内容冲突或写入／同步失败则拒绝替换原工程。后续 format-2 保存不覆盖该备份。
- 若此前没有磁盘工程文件，则不伪造旧工程备份。备份是转换前磁盘上的单页版本，不是多页工作的持续历史记录。
- 读取同时校验格式、页数、每页格数、每格音符数量、音高／音色／鼓声及全局设置；未知字段、尾随 JSON 和超过 1 MiB 的文件被拒绝。先用可变长数组解码，再检查格数，避免 Go 的固定数组解码悄悄截掉第 17 格。

回撤设备应用时，应先退出 Pinao，将当前 `song.json` 的多页版本另外复制保存，再将 `song.json.v1-backup.json` 的副本恢复为 `song.json`，然后使用旧版。**旧版无法直接读取 format 2；恢复单页备份也不会保留后来新增的多页内容，所以必须先另存当前文件。**如果备份不存在，先保留当前多页工程，再使用独立数据路径启动旧版；不要直接覆盖唯一工程文件。

## 刷新处理

按键、当前格变化、当前页变化立即进入画面差异检查，不再额外等后台 250 毫秒检查周期。相同可见状态和相同帧仍去重，异步写屏只保留最新待显示帧，不积压过时画面、不让音频等屏幕。

这只减少软件提交延迟，不修改驱动或提高电子纸物理刷新率；无法保证真机每一格都独立显示，也没有根据驱动字符串推断刷新配额或帧率。

## 本地验证

本次已执行并通过：

- `go test ./...`：既有测试与新增多页、页码绘制、安全边界测试。
- `go vet ./...`。
- `go test . -run 'Test(Multipage|Page)' -count=20`：最终改动后的专项测试 20 轮。
- `build.ps1 -Version 0.1.6 -OutputPath build/multipage-0.1.6/pinao`：主机测试、vet、Linux/mipsle hardfloat 静态构建及原生 ELF 校验通过，确认为 ELF32 little-endian MIPS32r1/r2、o32、双精度硬浮点 ABI。
- 单页至 64 页的页码布局测试；正常界面除页码区域外的像素哈希与原版一致，帮助页另行校验。
- 跨页播放的全部起点、首尾循环、量化边界、调速相位、左右插入顺序、长按仅触发一次、64 页上限、清空确认和停止时跨页边界。
- 旧版文件备份、迁移失败保留原文件、最大密度 8192 个事件的保存读取、超限／未知字段／尾随数据／第 17 格拒绝、导出快照不共享音符数据。
- 完整 WAV 的 PCM 与独立平铺编曲参考逐字节对比，覆盖 1／3 页、120／137／180 BPM、空格点、三种音色及四种鼓声；验证页序、连续性、长度、单页兼容、取消及禁止覆盖已有文件。

当前环境的 WSL 没有可用 Go 工具链，Windows 也没有可用的 CGO C 编译器，本轮未运行 race 检查；历史版本的 race 结果不等同于本轮验证。
