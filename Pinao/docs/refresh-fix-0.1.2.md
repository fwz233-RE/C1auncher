## 行为

- 输入和导出完成通知可以绕过 250 ms 的后台检查时间，优先提交变化后的画面。声音命令仍先于绘制处理。
- 每个旋律键在松键后保留 1200 ms 视觉提示；实际保持状态从 Held 删除，并立即产生 off 命令，视觉提示不会延长声音。
- 移动粒子改为固定音名/鼓声提示。提示到期及循环进度仍通过后台检查更新。
- 新的可比较 viewState 只保存可见状态：音色、速度、音量、八度、演奏状态、循环占用/进度、琴键与活动提示、页脚。可见状态不变时不重新绘制；像素相同时不提交。
- 帮助页忽略不可见的循环进度/活动变化，关闭帮助时显示当前状态。
- 保留异步写屏和单个最新待显示帧，避免慢速写屏阻塞输入或积累过期帧。
- 失去输入同步或恢复长时间停顿时清空琴键提示；继续沿用已有 off-all 安全处理。

## 限制

- 这次是真机 CPU 上的逻辑测试，不是实体键到屏幕像素变化的延迟测量，也不是声学延迟测量。
- 1200 ms 提示只是提高短按可见性的策略；面板长时间繁忙时仍不能保证每次按键独立显示。
- 沿用现有 fast_refresh_only 快刷，没有新增硬件矩形局刷、修改波形或宣称面板速度突破。
- 尚未进行本版本的连续实屏弹奏、残影观察或长时间压力测试；发布安装及版本核验不代表这些物理体验已验证。
