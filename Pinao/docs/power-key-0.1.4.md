# Pinao 0.1.4：电源键共享

发布日期：2026-09-07。仅发布服务器，未通过 USB 安装或测试，不修改核心、其他应用或用户工程。

## 实现

- `input_devices.go` 把输入打开策略从硬件适配层提取出来：event0（字母矩阵键盘）继续 EVIOCGRAB，event1（gpio_keys，包含实体电源键）只普通打开，不独占。不同 evdev 文件描述符各自收到一份事件，应用读取不会消耗核心的事件。
- `platform_device_linux_mipsle.go` 使用该策略，仍先发布 direct 显示模式，退出关闭描述符释放自己的独占，不再对共享设备调用解除独占。
- `resources.go` 与 `model.go` 共用退出键判定，去掉 143；143/116 明确保留给系统，不影响演奏、循环、逐格录制、帮助或导出。Home/Back/Esc 保留退出用途。
- 没有加入应用自己的关机命令，也没有改变界面布局、音频、工程格式或保存路径。

## 前提与边界

需要运行包含电源键长按修复的 C1ancher 核心。该核心在 direct 应用运行时先处理电源键，再忽略普通页面导航；因此共享 gpio_keys 不会让方向和音量键同时操作后台桌面。Home 仍有核心已有的返回桌面处理。

只升级 Pinao 不能修复旧核心。核心主循环卡住时仍不能保证响应；实际正常关机和数据落盘的时限仍取决于系统停止服务流程。本版未进行设备按键、显示、音频或断电验证，不能宣称已经实机验证关机成功。发布采用现有输入设备编号约定，不适用于设备节点映射不同的硬件。
