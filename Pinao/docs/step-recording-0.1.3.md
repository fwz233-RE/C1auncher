# Pinao 0.1.3：逐格录制

日期：2026-09-06。

## 用户确认的交互

- 上／下调 BPM；独立音量键调音量；左／右切换逐格模式并移动一格。
- R 开始录制，默认自动走格；再次按 R 结束录制。
- 自动录制时拨左／右，暂停时钟，保留录制状态，新音符写入当前选中格。
- **逐格录制时按空格，保持录制，从当前格恢复自动循环，直到按 R 结束。** 此项是用户在确认问题中明确指定的行为，不是“从第 1 格只播放”。
- 只做本地编译、验证与服务器发布，不安装、测试或接管 USB 设备。

## 边界行为

- 自动走格时方向输入以实际时钟位置计算，而非最后一次屏幕提交的位置；左退／右进一格后停住。
- 空闲且尚未选格时第一次左右输入选中第 1 格；之后首尾环绕。
- 未开启录制时，左右只选格，琴键／鼓键只试听，不自动写入；按 R 从选中格开始自动录制。
- 逐格时再按 R 结束录制后，停在原格供浏览；自动模式结束录制则继续循环播放。
- 逐格浏览按空格同样从当前格播放，但保持“未录制”；自动循环中再按空格仍是停止并解除录制。普通停止后再播放从第 1 格开始。
- 逐格录制在一格中可加入多个琴音与鼓声，最多 8 个；同音高、同音色、同鼓声的重复事件去重，其他已有事件保留。没有增加删除单个音符的操作，Delete 两次仍清空整个循环。
- 自动录制仍按最近半拍格量化；逐格录制不依赖经过时间，也不会弹一个音就自动跳格。
- 进入逐格停止已有循环声部，但不丢弃现场持键的松键事件；进入导出统一清理播放、录制及逐格状态。
- BPM 每次上下调整 5，限制 60–180；自动播放时保留格号及格内进度，避免调速导致回到开头或重复触发已播放格。

## 界面与存储

- AUTO REC 为自动录制，STEP REC 为逐格录制，STEP 为逐格浏览，LOOP 为自动播放。
- 上方增加 01/16–16/16 格号，逐格模式的下方选中格有额外方框。
- 逐格时音名和鼓声条显示选中格已有内容；键盘仍显示现场短按提示。自动模式继续显示近期活动。
- 帮助页面、页脚和 README 同步更新。
- Song 的 format 1 及原来的六个 JSON 字段不变，仍为八拍／16 格。手动光标和录制开关不写入工程，重新打开不会自动录制。
- 保留 6 MiB Go 软内存预算、八声部上限、32 项活动提示缓冲和异步最新帧写屏。
