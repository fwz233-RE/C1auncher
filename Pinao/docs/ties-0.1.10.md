# Pinao 0.1.10：逐格延音

## 操作

1. R 开始录音，左右摇杆进入逐格录制。
2. 在选中格按下琴键并保持，向右移动：每移动一格延长半拍。
3. 松开琴键，再向右移动：不再延长，不新增音，也不擦除目标格原有内容。
4. 多个琴键同时按住可延长和弦；鼓声维持原来的单格触发。
5. 连续延音格之间以两像素黑线相连；跨页在页面进度条两端显示短线。

向左仅导航，不延长；第16格右移维持原来的页内回到第1格，不跨首尾相连。在第16格持键时用 O 短按进入已有下一页，或长按插入下一页，可从下一页第1格继续延长。

## 与已有编辑功能的关系

- 仅在逐格录制时捕获按键；浏览、帮助、自动录制不会偷偷写入延音。
- 使用最初按下时的音高和音色。持键期间切八度或音色不会把长音中途改调。
- 松键、输入复位、结束录制、开始播放、向左回看会取消本次延音捕获。
- 目标格已有独立同音时保留该次起音，不自动合并；满格不替换已有音，也不越过满格接续。
- 在延音格松开再按同一琴键，将该音改为新起音，不增加重复事件。
- Delete 清空当前格并终止本次持键延长。后续与被删格断开的连音转为独立起音；其他格音符保留。Delete 二次确认清空整个工程的原有行为不变。
- 插入空白页会断开原来的跨页连接；不会跨空白页错误延长。
- Enter 保存、自动保存时机、音色合成参数、音量和节拍设置不变。

## 回放与资源控制

实时回放和 WAV 导出共用一个固定8声部的序列命令生成器。跨格保持相同声部 ID，不执行 NoteOff/NoteOn，也不重启包络或相位；新起音仍重新触发。和弦顺序变化不会把延音接到错误音高。每格最多9条命令，与既有队列/缓冲容量一致。

从延音中间开始播放、长时间卡顿跳格、或原声部已被现场演奏替换时，允许从当前格重新起音，不补播历史格。停止、导出取消和退出仍释放声音。延音会继续自然衰减，并不是恒定音量的持续声。钢琴音色算法没有在此版本修改。

## 工程兼容与回退

`Hit.tie` 省略时仍为旧版单格音；首次实际写入延音才升级工程到 format 3。旧 format 1/2 可以打开且不要求立即迁移。首次将旧工程保存为 format 3 前，按原文件字节创建不可覆盖的 `song.json.pre-ties-<SHA256>.json` 备份；不同旧工程修订使用不同备份名，备份冲突则拒绝覆盖。

旧应用无法读取 format 3。回退前先另存新工程，然后用对应 `pre-ties` 备份恢复旧工程，备份不含本次新增延音内容。应用更新本身不会替换用户工程。
