# 0.1.3 更新说明

## 重新制作大格地图预览

预览改为和游戏实际布局一致的 12×5、24px 大格，并采用密集城市街区构图，明确展示建筑块、道路和树林的可读比例，不再使用旧版 18×9、12px 的稀疏展示方式。



## 更大的地图视觉比例

将战场从 18×9 个 12px 小格调整为全宽 12×5 个 24px 大格。地形纹理、单位标记、迷雾、归属线、移动路径和光标均按大格重新布局，让小屏幕上的主要地貌和部队更容易辨认。地图信息栏改为底部状态提示，完整保留操作功能。



## 修复终端画面覆盖游戏

0.1.0 用不支持 `-mode` 的旧 Windows 发布器上传，清单没有 `direct` 模式。对于不在内置名单里的应用，C1ancher 默认使用 terminal 模式，按键及终端更新仍可能引发终端重绘。游戏直接写 epaper，却没有持有 C1ancher 的硬件独占锁，因此后写入的终端帧会盖住游戏；再按拨杆使游戏产生新帧时才恢复。

0.1.1 同时修复发布和运行两层：

- 使用 Windows Publisher 1.1.0，以 `-entry inkwars -mode direct` 发布，生成含 `mode\tdirect` 的 C1PKG-PACKAGE 2 清单。
- 程序打开 epaper/evdev 之前取得 C1ancher 的硬件独占锁；若由 c1pkg 启动，则复用并验证其 exec 继承的锁。锁不可用时拒绝写屏，不靠周期性抢刷掩盖问题。
- 关闭并在正常退出时恢复 PTY 的回显；设备诊断改写 `/usr/data/inkwars/last-run.log`，不向正在显示的终端输出调试文字。
- 取得锁后首帧延后一个 700ms 节拍，让上一张终端快刷帧完成；无须拨杆输入即可显示首帧。
- SIGCONT 请求重绘，保持独占锁和开机预算；退出关闭设备后释放锁。

## 地形美术

保持 12×12 原生格、18×9 视口、296×152 纯黑白 1bit。重画草丛、成簇树冠、雪顶山峰、屋顶窗口、厂房烟囱、机场跑道、港口码头和总部旗帜。道路按邻接关系形成直线、弯道、丁字及十字交叉；河流按实际邻接连通；海洋有波纹、沿真实陆地绘制海岸。草地与森林使用由坐标决定的镜像变化，不引入动画或随机闪动。

地图单位、移动路径、迷雾、归属和光标仍在地形之上绘制。地形测试将独立图块黑位密度限制在 50% 以内，保留白色空隙。预览见 `build/previews/terrain-map.png`、`terrain-atlas.png` 和放大检查图；主机界面闭环的 15 张图也已重新生成。

## 验证与边界

- 多进程使用启动器原本的硬件锁函数验证：进入游戏后终端共享写屏锁无法获得，继承锁不会自锁，其他占用者使启动失败，休眠暂停仍持锁，退出恢复权限。
- 真实设备运行分支配合测试文件与 FIFO 输入：首帧无输入自动提交，OK 按键后终端仍无写屏权限，恢复时重绘，预算 30 保持不变。
- 地形 11 类区分度、所有 16 种道路／河流邻接组合、岸线、绘图越格／越屏与非法坐标测试。
- 规则／存档 19,063 项检查及九回合 UI 闭环继续通过，存档格式没有修改，兼容 0.1.0。

本次 ADB 没有连接设备。锁与设备分支测试使用真实 Linux 文件锁和输入事件结构，但测试屏幕是普通文件，不是物理电子纸。当前不能声称用户手按现象已在真机重新验收。上一轮暂停启动器的写屏测试漏测了并发覆盖；测试脚本已改为让启动器保持运行，后续接机验证不能再暂停它。

完整功能缺项仍见 KNOWN_ISSUES.md。新版本没有通过提高刷新频率或恢复刷新额度处理问题。
