# 墨纸战争 / Ink Wars 0.1.1

0.1.1 修复启动器终端帧覆盖游戏的问题，并重画全部地图地形。新版本使用直接显示模式及硬件独占锁；详见 [更新说明](CHANGELOG.md)。0.1.0 存档可继续读取。本轮没有连接真机，新的显示修复已做多进程与设备运行分支回归，物理面板需接机再验收。

面向 C1-Slim 的原创中文单机回合制战棋。借鉴 Advance Wars 的生产、移动、占领和回合指令结构；**不是 GBA 原版移植或完整规则复刻**。没有使用 Nintendo 的 ROM、精灵、地图、音乐或对话素材。本次对话未提供可读取的参考附图，因此界面按文字要求重新设计，不能声称与附图逐像素一致。

## 快速开始

设备端无需网络、字体安装或共享库。解包后执行 `payload/launch.sh` 即可启动；正常启动后不会打开任何网络连接。

- 设备二进制：`build/inkwars`。
- c1pkg 包：`build/package/packages/inkwars/0.1.1.tar.gz`。
- 源码包：`build/inkwars-source-0.1.1.tar.gz`，包括构建所需的复用代码和许可证。
- 单色预览：`build/previews/*.png`，总览 `build/previews/contact.png`。
- 真机测试记录：`build/device-test.log`。

**本地工具输出的离线包未签名，正式服务器发布记录见 PUBLISHED.md。** `catalog.json` 的 `displayName` 为 ASCII `Ink Wars`，包内界面为中文。包采用 GNU tar 的 `manifest.v1 + payload/` 布局，清单格式为 **C1PKG-PACKAGE 2，mode=direct**；需要支持该格式的 C1ancher。正式发布使用 Windows Publisher 1.1.0 或更新版本的 `-mode direct`，由服务器生成签名索引，不替换设备信任根。发布后验证工具检查签名索引、包哈希和 direct 清单。

在设备终端手动离线部署到新目录的示例（先将包复制到设备）：

```sh
mkdir -p /usr/data/inkwars-local
cd /usr/data/inkwars-local
tar -xzf /path/to/0.1.1.tar.gz
./payload/launch.sh
```

发布包以 `inkwars` 静态 ELF 为入口，符合服务器入口校验；程序自身将存档写入 `/usr/data/inkwars/inkwars.sav`，不依赖工作目录，也不会写入只读包目录。`launch.sh` 保留作为手动启动入口。通过签名仓库安装后使用 `c1pkg launch inkwars`。**当前测试部署不是包管理器安装，不会自动新增其应用列表条目。** 不要同时运行其他直接写屏程序；正式应用入口应由 C1ancher 启动，以交接屏幕和前台会话。

## 操作

设备只接受已经确认存在的方向键、OK(352)/ENTER(28)、BACK(158)，不使用鼠标、触摸、字母键或删除键。

1. 主菜单选择“新建对局”。上下选设置行，左右或 OK 更换地图、双方指挥官、单双人模式和迷雾，选“开始对局”。
2. 方向键移动光标，视口自动跟随。地图可视 18×9 格，每格 12×12 像素；右下角是全图缩略图。
3. 选空闲自军后显示移动范围和路径；选择目的格、OK 确认，再选“攻击／占领／待机”。**在原格再次 OK 可原地执行指令**，不消耗移动，适用于火炮和连续占领。
4. 攻击面板按方向切换合法目标，确认后显示一次数值结算；OK 返回。敌方攻击也显示结算，需要确认继续。
5. 选己方空工厂、机场、港口进入生产；上下滚动兵种，OK 扣款生产。新兵本回合已行动。
6. BACK 打开回合菜单：结束回合、能力、超能、全图、保存、保存退出、返回。
7. 热座换边先显示交接遮挡页，下一位玩家 OK 后才显示其视野。单人敌方回合始终保留玩家甲方的迷雾视角。

移动已确认后 BACK 只是关闭指令框，不撤销移动或返还燃料；可重新选择该单位完成剩余指令。移动路径遇到隐蔽敌军会停在合法位置并结束行动。敌军自动行动期间不能替它生产或下令；战斗结算页可以确认。

兵种符号为 I 步兵、M 机步兵、R 侦察车、T 坦克、A 火炮、X 防空车、F 战斗机、B 轰炸机、C 战列舰、L 侦察艇。

显示规则：自军空心框、敌军反白，角部缺口表示已行动，受损单位底部短线表示剩余生命。地形用独立线条图形，迷雾用规则黑点；移动范围以角点标记、路径以中心短块标记。城市归属使用实线或点线；完整 HP、燃料、弹药在信息栏／单位资料内，占领中显示剩余占领点。没有灰度、彩色、透明、渐变或抗锯齿。

## 已实现规则

- 三张原创 30×18 地图：青岚河谷、潮汐双湾、赤岩高地，包含平原、森林、山地、河流、海洋、道路、城市、工厂、机场、港口、司令部。双方港口的航道连通。
- 十类单位：步兵、机步兵、侦察车、坦克、自行火炮、防空车、战斗机、轰炸机、战列舰、侦察艇。侦察艇是无武装海上侦察单位，**没有载运能力，不冒充登陆艇**。
- 地形移动费用、可达范围、最短路径与路径燃料消耗；山河限制、海陆空通行差异；射程、弹药、间接火力移动后禁射。
- 战争迷雾、属性与单位视野、步兵登山视野、森林地面单位相邻侦察、隐蔽阻挡。
- 每座己方建筑每回合收入 1000，开局基础资金 10000，第一方开始时结算收入；生产设施分类与格子占用检查。
- 占领需 20 点，仅步兵／机步兵，每次减少 `ceil(HP/10)`；离开或阵亡重置。占领总部或歼灭敌军获胜。
- 兼容己方设施回合开始时修理至多 20 HP，按实际修理比例扣款，并补满油弹；后勤指挥官修理上限 30 HP。
- 单人 AI 和本地热座；AI 使用可见敌情评估目标和伤害，不直接读取隐蔽敌军作为决策目标。

### 伤害与指挥官

HP 为 0–100，无随机数。基础伤害矩阵见 `src/game.c` 的 `base_damage`。依次整数向下取整：

`基础伤害 × 攻方HP/100 × 攻击倍率/100 × 防御系数/100`

防御系数为 `max(20, 100 - 地形星数×10×守方HP/100 - 指挥官防御加成)`，飞机不享受地形防御。合法非零伤害最低 1 HP，实际扣血不超过剩余 HP。反击用受击后 HP 计算，必须满足射程、弹药、非间接火力等规则。预测与结算调用同一套公式。

- 顾岳·突击：常态地面攻击 +5%；能力额外 +20%、超能额外 +35%，超能移动 +1。
- 林岚·守望：视野 +1，森林／山地防御 +5%；能力／超能防御 +15/+25，额外视野 +1/+2。
- 苏澜·后勤：生产九折；能力／超能补满油弹、回复 10/20 HP、移动 +1/+2。
- 双方按实际受损 HP 获得能量，最多 1000；能力消耗 300，超能 600，每回合一次，效果在本方回合结束失效。

顶栏的“日”目前是**换边次数**，每次结束回合都加一，不是原版双方共同的天数计法。

## 电子纸与存档

复用 `ChiChuGames/src/gfx` 的 1bit 绘图和 ASCII 点阵；中文为仓库 C1 Package Bitmap / GNU Unifont 的原始 16×16 点阵子集。只在构建时提取，不使用运行时字体栅格化库。

显示帧为 5624 字节，黑位=1，纵向八行条带排列。仅在完整写入成功后更新去重缓存。普通可见操作和软件方向重复最短 700ms；没有连续动画、逐像素滚动、自动闪烁。空闲用阻塞 `poll`，释放事件优先于软件重复处理。SIGCONT 只请求快刷重绘，绝不恢复刷新额度。

全刷只来自场景／回合／结算切换请求，合并请求并在主循环空闲处、距写帧至少 700ms 且距全刷至少 5 秒时尝试。按 boot ID 持久保存保守额度，快刷预扣 1、全刷预扣 8，总额度 30；不写 `refresh_cnt` 或 `refresh_max`。计数下降、计数不可读或预算文件异常时禁用全刷。全刷前临时关闭 fast-only，结束后恢复；恢复失败立即停止写屏。

**物理限制：**全刷 syscall 会阻塞约 1.5–2 秒或更久，期间无法承诺 700ms 显示响应；软件不主动清按键队列，但内核队列仍可能溢出。30 的预算耗尽后只使用快刷，因此不能保证无限时长完全无残影。当前设备计数已为 30，实测未改变它；有余额时的全刷波形尚未真机验证。

存档采用小端字段序列化、版本 1、CRC32、全字段与局面合法性校验，大小 2627 字节。临时文件→文件 fsync→原子 rename→目录 fsync。加载失败不改变当前局面；损坏的已有文件拒绝覆盖，也不会自动删除。目录 fsync 若失败，可能已经替换成功，界面显示“保存未确认”，具体错误见 stderr。仅支持一个正常存档槽；遇到损坏需先由用户另存原文件，再移走原路径建立新档。支持 SIGHUP/SIGTERM 等退出前尽力保存，SIGKILL／断电无法捕获。

## 构建、主机试玩与测试

Linux / WSL Ubuntu 22.04：

```sh
sudo apt-get install build-essential gcc-mipsel-linux-gnu binutils-mipsel-linux-gnu python3 python3-pil qemu-user
cd InkWars
make host test target verify previews mips-test package
python3 tools/host_viewer.py
```

浏览器访问 `http://127.0.0.1:8768`，方向／Enter／Escape 操作。网页只是本地主机预览，游戏规则、中文绘制和像素都来自 C 程序。主机视图允许测试按钮，**设备程序没有鼠标或触摸输入路径**。终端也可以直接运行 `build/inkwars-host`，用 `w/s/a/d`、回车、`b` 操作，同时写出 PBM。Windows 可运行 `powershell -File .\build.ps1 -Play`。

目标编译为 Linux MIPS32r2 小端、o32、硬浮点 FP32 静态 ELF，启用 64 位文件接口以处理大 inode；没有动态解释器或共享库依赖。新游戏规则、绘图、输入层没有显式 malloc；libc 文件 I/O 和启动时继承锁描述符枚举可能使用少量内部堆分配。

需要修改中文文案时先运行 `python3 tools/font_subset.py`。正常构建直接使用已生成的 `src/cjk.h`，不联网。测试与当前真实缺项详见 `TESTING.md`、`KNOWN_ISSUES.md`。
