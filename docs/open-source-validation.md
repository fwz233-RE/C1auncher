# 本次源码汇总的验证记录

日期：2026-09-07。以下记录单仓库源码整理和开发者发布工具的验证结果；2.0.0 安装器及普通应用发行附件的核验见 [2.0.0 发行说明](release-v2.0.0.md)。这些检查不是整机固件验收。

## 已执行并通过

- 核心：WSL Ubuntu 22.04 执行 `make -j2 host-test all`，完成主机测试，以及 C1ancher、启动器、`c1pkg`、`c1updater` 四个静态 MIPS 设备产物和构建自带的架构检查。
- Go 代码：Windows Go 1.26.4 分别在 `App/c1device`、`App/hello`、`App/book-reader`、`App/music-player`、`App/pic` 和 `Pinao` 执行 `go test ./...`、`go vet ./...`，并以 `GOOS=linux GOARCH=mipsle GOMIPS=hardfloat CGO_ENABLED=0` 交叉编译。共享模块只编译库，其余输出设备程序。
- 游戏：WSL 执行 `make -j2 host-test target verify`，主机游戏逻辑/输入测试及 MIPS 构建、架构检查通过。
- 安装器：`dotnet run --project C1ancher/installer/tests/Installer.OfflineTests.csproj -c Release`，结果为 **660 passed、0 failed、0 skipped**，包括模拟安装、进程识别和失败保护。使用假 ADB，没有连接真实设备。
- 最小 C 示例：本机编译与 `--version` 检查通过；交叉构建验证 ELF32、MIPS 小端、o32、MIPS32r2、双精度硬浮点，并检查没有动态解释器/动态库依赖。
- 独立源码验证：使用 Git 暂存区导出源码快照，重新完成核心主机测试及四组件构建、六个 Go 模块交叉构建、游戏交叉构建和最小 C 示例构建。

## 发布工具包

- 三个客户端沿用原有 2026-09-06 分发的二进制，逐个匹配固定 SHA-256，未重新编译或加入生产凭据。
- 检查 Windows PE 的 x64 架构；检查两个 Linux ELF64 的 x64/ARM64 架构和没有动态解释器/动态段。
- Windows x64 和 WSL Linux x64 客户端实际执行 `-help` 成功；ARM64 仅做静态格式和构建元数据检查，未在 ARM64 机器运行。
- 最终 ZIP 只包含九个明确成员：三个客户端、公开地址、公钥、README、分发说明、Go 第三方许可和逐文件校验清单。
- ZIP 成员集合、CRC、解包字节与 SHA-256 均已检查。公开文本文档按 LF 归一化后打包。
- 没有在本次验证中向生产应用服务器上传新应用，也没有以一次帮助命令代替线上端到端发布验证。

## 源码检查

- 暂存区没有 `160000` 类型的子模块条目，普通应用源码随同一个仓库完整提供。
- Pinao 原始设备记录和维护者授权/发布脚本保留本地并排除；公开核心文档和安装器预览中的具体设备标识已移除。
- 对待公开内容及继承的 main 历史进行了常见私钥、GitHub 令牌、云访问密钥和可疑嵌入凭据模式检查，未发现这些高置信度模式。模式扫描不等于完整安全审计，也不保证识别所有秘密格式。
- 源码空白检查通过，但保留 GNU Unifont 上游许可的原始换行，以及两份既有生成资源数组末尾的空行；未为了格式检查改写这些原始/生成内容。

## 验证限制

- 本次没有连接或操作真实设备，没有安装、重启、休眠、关机或修改生产服务器。
- 本机测试和交叉编译不等于电子纸、实体按键、音频、功耗或长时间运行的实机验证；Windows 测试不会执行仅限 Linux/MIPS 的测试分支。
- 上述 Go 交叉构建产物用于源码检查，不替代完整应用发行包。自行重新打包阅读、音乐、图片应用时，需要提供合法兼容字体并附带其许可。
- 官方安装器和核心发行包按配套签名清单校验，安装前应阅读对应版本说明。
- 公共源码许可与第三方声明提供了明确的分发范围，不替代针对未来新增素材、依赖或贡献的许可检查。
