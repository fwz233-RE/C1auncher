# C1-Slim 自助发布器 1.1.0

发布日期：2026-09-07。此版本独立于设备核心 2.0.0，不需要重装设备系统。

## 下载与使用

下载本页的 `C1Slim-Publisher-1.1.0.zip` 和同名 `.sha256`，核对后解压并保留整个目录。Windows 用户双击 `c1publish.exe`，按中文菜单注册作者、保存令牌、发布已编译的应用。Linux x64/ARM64 程序包含在同一个包内。

旧的 `C1Slim-Publisher-20260907.zip` 不支持注册，应改用新版。旧附件保留，避免更换已有下载内容。`-tool-version` 应显示 `C1-Slim Publisher 1.1.0`。

## 本次新增

- 自选未占用的作者名，自助生成并登记随机发布令牌，无需管理员审批。
- 首次成功发布未占用、未受保护的新应用 ID 时，自动登记作者归属。同一作者可发布多个新应用，现有有效令牌同样支持。
- 已归属应用只能由对应作者更新，版本和 ID 冲突不会覆盖既有内容。
- 注册先保存令牌再发请求，相同作者和文件可安全重试；发布器避免将正在使用的令牌文件误打入上传包。
- 服务器持久保存令牌哈希及应用归属，与签名目录一同原子提交，并在重启时验证完整性。
- 公开发布器及共用服务器 Go 源码、测试和跨平台打包脚本。

## 验证结果

- Windows `go test ./...`、`go vet ./...` 通过。
- Linux `go test -race ./...`、`go vet ./...` 通过。
- 构建 Windows x64、Linux x64/ARM64 发布器，以及静态 Linux x64 服务程序；ZIP 文件清单、CRC、逐文件哈希和程序架构验证通过。
- 官方服务器启用自助注册，并保留现有作者授权、可信公钥和资源限制。
- 用发行包里的 Windows EXE，通过默认域名及既有官方 IP 回退，完成真实注册、注册重试、`self-service-demo` 首发 0.1.0、更新 0.1.1 和相同内容重试。
- 验证跨作者更新、匿名更新受保护应用均被拒绝；服务器重启后身份和归属仍有效。
- 验收时目录序列由 128 递增至 130；原有 8 个应用的作者、版本、包哈希及元数据均保持不变。

`self-service-demo` 是终端文字示例，不写设备设置或个人文件，源码位于 `C1ancher-server/examples/self-service-demo/`。本次只验证发布服务，没有将示例安装到设备，也没有声称完成设备实机验收。

## 边界与风险

- 工具负责注册、打包和上传；开发者仍需提前编译符合 C1 规格的设备应用。
- 作者名是自选唯一名称，不是实名认证。令牌必须私下备份；当前没有丢失后的自助找回或换发功能。
- 已发布的匿名应用仍然是匿名应用，不能被新身份自动认领；例如现有 `remoteagents` 的匿名归属未被本次升级更改。旧的显式 `-open` 仍不提供独占更新权。
- 默认保留现有 HTTP 服务，需要显式确认风险；HTTP 可能暴露令牌并允许上传内容被篡改，验签公钥不能保护上传链路。
- 开放注册有全局速率和数量限制，不代表无限容量或内容安全审核。原有应用和系统核心的权限保护保留。
