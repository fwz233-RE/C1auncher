### P1: 启动测试

| 编号 | 操作 | 预期结果 |

| P1.3 | 检查终端模式 | 终端处于 raw 模式，输入立即响应 |

### P2: 英文模式测试

| 编号 | 操作 | 预期结果 |

## 测试执行

```bash
# 1. 编译
make build

# 2. 运行基础测试
./test/test_all.sh

# 3. 在真实终端中运行交互式测试
./build/term-ime

# 4. 按 P1-P8 顺序执行测试用例
```
