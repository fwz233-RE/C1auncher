Runtime contract
----------------
Entry: bin/c1-ime-service
Arguments: --prebuilt-only --socket /absolute/private-runtime/socket
           --shared-data /absolute/install-root/share/rime-data
           --user-data /absolute/dedicated-private-user-directory
Socket parent and user-data must be service-owned 0700 directories. The caller
controls foreground process lifetime, waits for protocol READY and provides
English fallback. Never remove --prebuilt-only on the constrained device.
Missing prebuilt files fail closed; runtime may create small YAML settings and
normal learning databases but never rebuilds dictionary binaries in this mode.
QEMU results and memory figures are simulation only, not device acceptance.
