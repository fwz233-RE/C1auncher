# 快捷键

| 快捷键 | 功能 |
|--------|------|
| `^A` + `Space` | 切换中英文模式 |
| `^A` + `S` | 打开设置面板 |
| `^A` + `^C` | 退出 term-ime |
| `1` - `9` | 选择候选词 |
| `Space` | 选择首个候选词（候选状态时） |
| `Backspace` | 删除单个拼音字母 |
| `Esc` | 取消输入 |
| `,` / `<` | 上翻候选词 |
| `.` / `>` | 下翻候选词 |
| `'` | 拼音分隔符（如 `ni'hao`） |
| `exit` | 退出 shell |
