C1 Publisher binary distribution

The maintainer distributes these official c1publish binaries for developers
who wish to package and upload ordinary applications to the existing C1
application service. Application compilation is a separate step.

This developer kit provides client executables and their configuration.
The GPL license of the separate C1ancher device-side project does not by
itself relicense these independent publisher executables. This distribution
note does not introduce a new open-source license for the publisher.

Retain the accompanying third-party copyright and license notices. The Go
runtime and listed standard-library dependencies are described in
THIRD_PARTY_NOTICES.txt. Server access remains subject to the actual service's
availability and publication rules; this kit grants no administrator access,
signing authority, or exclusive ownership of anonymously published app IDs.
